# ArDem

An SSH client for Windows that keeps the terminal, the file manager, a code editor and a browser **on one connection**.

**Download:** [dem-work.com](https://dem-work.com/#ardem), or the latest `ArDem-Setup-<version>.exe` (installer) or `ArDem-Portable-<version>.exe` (no installation) from [Releases](https://github.com/dagafitei72-cpu/ardem-releases/releases/latest).

Windows 10 or 11, 64-bit. ArDem is open source under the MIT license, by Dandem.
